# Domain lexicon, English to Spanish

<!--

-->

Use these terms consistently. When a platform shows a label in English to sellers (for example "economic operator" on Etsy, or a field name in Amazon Seller Central), keep that label exactly as the seller sees it, in quotation marks, and explain it in Spanish.

| English | Spanish |
|---|---|
| General Product Safety Regulation (GPSR) | Reglamento General de Seguridad de los Productos (GPSR). Keep the acronym GPSR, which sellers know |
| Responsible Person, EU Responsible Person | persona responsable, persona responsable en la UE |
| economic operator | operador económico (and the platform label "economic operator" when the article describes that screen) |
| manufacturer | fabricante |
| importer | importador |
| distributor | distribuidor |
| fulfilment service provider | prestador de servicios de tramitación de pedidos |
| online marketplace | mercado en línea |
| market surveillance authority | autoridad de vigilancia del mercado |
| technical documentation | documentación técnica |
| risk analysis | análisis de riesgos |
| safety information, warnings | información de seguridad, advertencias |
| product identifier (batch, serial number) | identificador del producto (número de lote, número de serie) |
| label, labelling | etiqueta, etiquetado |
| recall | recuperación del producto |
| withdrawal | retirada del mercado |
| Safety Gate | Safety Gate (el sistema de alerta rápida de la UE) |
| CE marking | marcado CE |
| declaration of conformity | declaración de conformidad |
| customs | aduanas |
| VAT | IVA |
| Import One-Stop Shop (IOSS) | ventanilla única de importación (IOSS) |
| packaging and packaging waste | envases y residuos de envases |
| seller | vendedor, vendedora |
| EU, European Union | UE, Unión Europea |
| eligibility quiz | test de elegibilidad |
