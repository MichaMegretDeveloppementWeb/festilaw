# Domain lexicon, English to French

<!--
Termes du domaine, a garder constants d'un article a l'autre. A completer quand une relecture de Laetitia
corrige un terme. Les libelles d'une plateforme restent tels que le vendeur les voit a l'ecran.
-->

Use these terms consistently. When a platform shows a label in English to sellers (for example "economic operator" on Etsy, or a field name in Amazon Seller Central), keep that label exactly as the seller sees it, in quotation marks, and explain it in French.

| English | French |
|---|---|
| General Product Safety Regulation (GPSR) | règlement général sur la sécurité des produits (GPSR). Keep the acronym GPSR, which sellers know |
| Responsible Person, EU Responsible Person | personne responsable, personne responsable dans l'UE |
| economic operator | opérateur économique (and the platform label "economic operator" when the article describes that screen) |
| manufacturer | fabricant |
| importer | importateur |
| distributor | distributeur |
| fulfilment service provider | prestataire de services d'exécution des commandes |
| online marketplace | place de marché en ligne |
| market surveillance authority | autorité de surveillance du marché |
| technical documentation | documentation technique |
| risk analysis | analyse des risques |
| safety information, warnings | informations de sécurité, avertissements |
| product identifier (batch, serial number) | identifiant du produit (numéro de lot, numéro de série) |
| label, labelling | étiquette, étiquetage |
| recall | rappel de produit |
| withdrawal | retrait du marché |
| Safety Gate | Safety Gate (le système d'alerte rapide de l'UE) |
| CE marking | marquage CE |
| declaration of conformity | déclaration de conformité |
| customs | douane |
| VAT | TVA |
| Import One-Stop Shop (IOSS) | guichet unique à l'importation (IOSS) |
| packaging and packaging waste | emballages et déchets d'emballages |
| seller | vendeur, vendeuse |
| EU, European Union | UE, Union européenne |
| eligibility quiz | test d'éligibilité |
